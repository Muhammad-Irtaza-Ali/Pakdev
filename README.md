# PakDev — AI Development Workspace

A TypeScript/React development-workspace prototype with a Monaco editor, file explorer, workspace state, and AI-tool integrations.

**Category:** Web application prototype

## Start here

Install dependencies from the root with `npm install`, then use `npm run dev` or `npm run build`. The package also contains a Bun lockfile. Supabase functions and environment configuration are needed for connected AI features; the UI alone does not verify those integrations.
